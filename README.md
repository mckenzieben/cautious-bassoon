# Australian Government (author-date) Reference Generator
An HTML- and JavaScript-based generator for in-text citations and full references following the Australian Government (author-date) style, as used by Collarts.

Currently supports books, journal articles, websites and podcast episodes. Note that URLs are presented in the printed format, with the full URL - not a hyperlinked title. (A flag to choose this behaviour could be added.)

Originally created under the name "cautious bassoon".
